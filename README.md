# 大明：蝴蝶效应 (Ming: Butterfly Effect)

> 崇祯十七年（1644年）历史策略模拟游戏

## 简介

扮演崇祯帝朱由检，在王朝最后的春日里做出抉择。李自成的大军正向北京逼近，关外的清军虎视眈眈，国库空虚，朝堂倾轧。每一个决定都将如蝴蝶振翅，引发不可预知的连锁反应。

## 玩法

- **三阶段回合制**：早朝（处理奏章）→ 施政（调配资源、颁布国策）→ 结算（蝴蝶效应显现）
- **蝴蝶效应引擎**：30条传播规则，每项决策追溯6级因果链
- **10个地区 + 28个次要地点**：山海关、潼关、居庸关等历史关隘
- **12位历史人物**：吴三桂、王承恩、周皇后、李自成、多尔衮等
- **38个历史事件**：昌平陷落、吴三桂请饷、煤山时刻等
- **12项国家大政**：南迁之议、勤王令、罪己诏、联虏平寇等
- **6种结局**：煤山殉国、南明奠基、力挽狂澜、苟延残喘、开关迎虏、中兴之梦

## 运行

直接用浏览器打开 `game.html` 即可。无需安装任何依赖。

## 操作

- **新开始**：开始新游戏（自动弹出新手教程）
- **继续旧档**：从上次保存继续
- **早朝**：点击左侧事件卡片展开，选择应对之策
- **施政**：点击下方资源数字选中，再点击地图地区分配；点击国策按钮实施大政
- **地图**：滚轮缩放，拖拽平移，双击重置
- **存档**：自动保存，Ctrl+S 手动存档

## 技术

纯 HTML/CSS/JS 单文件，无外部依赖。SVG 矢量地图，CSS Grid 响应式布局。
